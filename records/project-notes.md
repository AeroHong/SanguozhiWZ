# 프로젝트 대화 정리

- 최종 통합: 2026-10-23
- 범위: `삼국지 왕전` 프로젝트의 관련 대화
- 정리 원칙: 사용자가 직접 확인한 사실만 남긴다. 이미지에만 있던 값, 대화 중 계산 오류가 지적된 값, 이전 답변의 추정은 확정 데이터로 저장하지 않는다.

## 덱·픽업의 확인된 이력

- 2026-09-24: 공손찬 3성을 달성했다. 구현령 135장으로 시작해 100장을 사용했고 35장이 남았다.
- 덱 완성에 무장 2명과 전법 1개가 더 필요하다.
- 선택 픽업은 무장 2명을 지정하며, 100장 안에 1명 보장·최대 200장으로 두 명 확보라는 규칙을 사용한다.
- 2026-10-16 원소 픽업은 잔액 586장일 때에도, 무장 성급 목적상 1장만 얻을 가능성이 큰 뽑기라 보류했다. 이는 당시의 판단 이력이며 현재 지침으로 자동 적용하지 않는다.

## 작전·자원 관련 대화

- 탈환 작전의 당시 최종 목표는 기현 5레벨 영토 점령 보상이었다.
- 가방 자원은 오래된 스냅샷과 최신 스냅샷을 혼합하지 않는다. 최신 확인값은 위 표만 사용한다.
- 옥재·이벤트 보상처럼 계산 중 수정되었거나 근거가 완전하지 않은 항목은 별도 확정 전까지 이 문서에 합산하지 않는다.

## 보류 항목

다음은 대화에는 언급되었지만 저장소의 확정 기록에는 넣지 않았다.

- 이미지에만 표시된 세부 연구·패키지·작전 값
- 계산 오류가 지적된 옥재 수급 세부 내역
- 이전 대화에서 제시된 확률, 가격 효율, 예상 수급량
- 현재 픽업의 구체적인 대상·우선순위·중단 기준

새로운 사실이 확인되면 `project-facts.csv`에 먼저 스냅샷 또는 규칙으로 기록하고, 장기적으로 필요한 내용만 이 문서에 반영한다.
