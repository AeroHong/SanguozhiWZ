용쟁호투 작전 브리핑

게임 내 "이벤트 규칙" 전체 화면(신청 조건부터 45분 타임라인, 산출 수치, 보상까지)을 캡처해 재구성한 자료에, 이벤트 재개와 함께 공지된 개편 내용을 반영했습니다. 패치 공지에 수치가 없는 항목은 "미확인"으로 남겨두고, 시즌 시작 후 게임 화면으로 채웁니다.

재개 시즌, 무엇이 바뀌었나

  • 시작 21:30으로 30분 늦춰짐. 행군 속도는 원 서버 지도와 동일.
  • 주력군·분대가 서로 다른 전장에서 각자 매칭 상대와 싸웁니다. 분대는 더 이상 주력군 전장의 파밍 인력이 아닙니다.
  • 조운부두·장작영 속성 버프 폐지 — 이제 1회성 포인트만 줍니다. 버프 운영이 목적이던 도하조는 의미가 사라졌습니다.
  • 건물당 주둔 상한 30부대. 한 건물 몰빵이 불가능해져 분산 배치가 기본이 됩니다.
  • 책략 시스템 개편 — 개인 책략 3종, 동맹 책략 5종(대장 사용). 대장은 5명.
  • 맹호성 포인트 가산 버프 신설, 도적거점 포인트는 라운드마다 증가, 중앙 비룡성은 3급으로 하향.
  • 개인 랭킹·이벤트 임무 폐지 → 개인 포인트 구간 보상(승리/패배 측 별도)으로 교체.
  • 그 외: 참가 관리 즉시 개방·자동 배정, 성 이전 조건 완화, 공격 범위 제한 취소, 채팅·좌표 이동·미니맵 등 UI 개선.
표시

01참가 자격 · 신청

신청은 동맹 단위입니다. 조건을 넘기지 못하면 애초에 대회 명단에 오르지 못합니다.

신청 조건 3가지 확인

동맹 생성일 15일 초과, 서버 랭킹 상위 20위 이내, 최소 동맹원 40명. 세 조건을 모두 충족해야 동맹 관리자(맹주·부맹주)가 수요일 01:00부터 신청할 수 있습니다. 신청이 완료되면 조건과 무관하게 모든 동맹원이 참가 가능합니다.

참가 관리·이벤트 준비는 신청 즉시 열립니다 확인

예전에는 토요일 09:00 매칭 공개 후에야 열렸지만, 이제는 동맹 신청이 완료되는 즉시 참가 관리(인원 배정)와 이벤트 준비(편성 복제, 지원 무장·전법·매 선택) 화면에 들어갈 수 있습니다. 매칭 상대는 여전히 토요일 09:00에 공개됩니다.

전시 기간은 종료 후 1일 확인

일요일 22:15 종료 직후 승패 보상과 개인 포인트 구간 보상이 우편 발송됩니다(부전승 보상도 종료 후 발송). 이벤트 데이터(전투 기록·상대 전략)는 월요일 01:00까지만 열람할 수 있습니다.

02참가 조직 구조

맹주·부맹주가 인원을 어떻게 나누느냐가 승패를 직접 결정합니다. 이번 시즌부터 주력군과 분대는 서로 다른 전장에서 싸웁니다.

주력군과 분대는 별도의 매칭 풀에서 각자 다른 상대를 만납니다.

분대 매칭 로직은 주력군과 동일합니다. 따라서 분대는 더 이상 주력군 전장 안의 파밍·견제 인력이 아니고, 주력군 전장의 모든 임무는 주력군 인원만으로 수행해야 합니다. 주력군의 승패가 동맹 승패를 결정한다는 원칙은 유지되는 것으로 보이나, 분대 전장 결과가 동맹 승패에 반영되는지는 공지에 없습니다.

대장은 5명 확인

동맹 대장 인원이 5명으로 늘었습니다. 대장만 지휘 기능과 동맹 책략을 사용할 수 있으므로, 번영도보다 실제 전투 감각이 있는 인원으로 인선하는 것이 유효합니다. 기본값이 여전히 "번영도 상위"로 자동 지정되는지는 미확인

신청 종료 5분 전 자동 배정 · 잠금 확인

미배정 인원은 번영도 순으로 주력군에 먼저 채워지고, 넘치면 분대로 갑니다. 미배정 인원이 없는데 주력군이 미달이면 분대 인원이 번영도 순으로 주력군에 끌어올려집니다. 이 시점에 인원이 최종 잠금되어 이후 재배정이 불가능합니다.

분대 배정은 주력군 정원을 채운 뒤에만 확인

동맹 참가 인원이 주력군 정원을 충족해야 분대 전장으로 인원을 보낼 수 있습니다. 배정한 인원은 맹주·부맹주가 다시 "미배정"으로 되돌릴 수 있고, 미배정 인원이 남아 있으면 관리자 화면에 레드닷이 뜹니다.

주력군·분대 정원과 신청 종료 시각 미확인

각 팀의 정원 상한과 신청 종료 시각(=자동 배정·잠금 시각의 기준)이 공지에 없습니다. 참가 관리 화면에서 확인해야 합니다.

  1. 신청 직후 참가 관리에서 주력군 인원부터 수동 배정 — 자동 배정은 번영도순이라 실전 감각과 다를 수 있습니다.
  2. 대장 5명 인선 — 동맹 책략을 쓸 사람들입니다.
  3. 신청 종료 5분 전까지 배정 확정 — 이후 잠금.
  4. 본전투 입장 시 전장 전환 버튼으로 본인 소속 전장(주력군/분대)에 들어왔는지 확인.

강화 효과의 크기는 여전히 비공개 미확인

공지는 "구체적인 강화 효과는 이벤트 선택 화면에 따름"이라고만 합니다. 전법 2개를 빌리는 쪽과 무장 1명을 강화하는 쪽 중 무엇이 유리한지는 준비 화면을 직접 열어봐야 판단할 수 있습니다.

04이벤트 책략

재개 시즌에 전면 개편되었습니다. 개인 책략은 각자 자기 부대에, 동맹 책략은 대장(5명)이 전체 동맹원에게 씁니다. 아군·적군의 책략 사용 현황(발동 중 잔여 시간 / 종료 / 미사용)이 전장에 표시되므로, 상대가 언제 무엇을 썼는지 보고 대응할 수 있습니다.

맹호성 과반이 6분, 비룡성이 7.5분입니다. 횡소천군·견불가최를 진입 시점에 함께 켜면 맹호성 과반 구간 대부분을 덮습니다. 늦게 켜면 과반이 확정된 뒤 효과가 낭비되므로, "쟁탈 개시 = 책략 발동"을 대장 간 약속으로 정해두는 것이 좋습니다.

책략별 최대 사용 횟수·재사용 대기 미확인

책략 목록에서 잔여/최대 횟수를 볼 수 있다고만 공지되었습니다. 횟수가 1회뿐이면 1차 쟁탈에 다 쓸지 2차를 위해 남길지가 핵심 결정이 됩니다. 대장 5명이 각자 쓸 수 있는지, 동맹 공용 횟수인지도 확인이 필요합니다.

05전장 건물 5종

이벤트 성지는 정비 → 쟁탈 → 산출 3단계(맹호성·비룡성) 또는 정비 → 쟁탈 2단계(그 외 3종)를 반복합니다. 쟁탈 기간에만 뺏고 뺏길 수 있고, 나머지 기간은 결과가 확정된 채로 흘러갑니다. 매 휴전(정비) 진입 시 소속이 초기화되어 다음 쟁탈 기간에 처음부터 다시 다툽니다.

모든 건물은 주둔 상한 30부대입니다.

재개 시즌에 확정된 규칙입니다. 주력군 전체를 한 건물에 몰아넣는 운영은 불가능하고, 30부대를 넘는 병력은 다른 건물로 나눠야 합니다. 같은 이름의 건물에는 이제 접미사가 붙어 전황 화면에서 구분됩니다(예: 맹호성 A/B — 실제 표기는 게임 확인 필요).

맹호성 3개를 두 사이클 모두 지키면 21,600점 — 여기에 가산 버프가 붙는 맹호성은 더 커집니다.

3,600×2사이클×3개 = 21,600점(가산 제외 기준). 비룡성 4개를 두 사이클 지켜도 2,700×2×4=21,600점으로 총량은 비슷하지만, 건물 수가 많아 병력이 더 분산됩니다. 주둔 상한이 30부대라 맹호성 3곳을 동시에 지키려면 최소 3개 조가 필요합니다. 가산 버프가 붙은 맹호성 → 나머지 맹호성 → 비룡성 순으로 우선순위를 둡니다.

가산 버프는 "유효 동맹 = 점령 동맹"일 때만 확인

쟁탈 기간 중 일부 맹호성에 가산 버프가 붙고, 전황 목록에 증가 아이콘이 뜹니다. 가산은 해당 맹호성의 유효 동맹과 실제 점령 동맹이 일치할 때만 적용되어 산출 기간 초당 포인트를 늘립니다. 정확한 배율과 "유효 동맹"의 판정 기준은 건물 정보 화면에서 확인해야 합니다 미확인

추격 메커니즘: 격차 50% 초과 시 발동 확인

양측 동맹 포인트 격차가 50%를 넘으면 열세 측에 추격 보정이 걸립니다. 대상은 맹호성·비룡성·도적거점 3종뿐이며, 이 3종 중 점령 중인 건물 단 1곳에서만 발동합니다.

계산 예시 (게임 공식 예시를 실제 수치로 환산) 확인

A가 B보다 60% 앞선 상황에서 B가 맹호성 2곳을 점령 중이라면, 그중 1곳만 산출량이 격차 비율만큼(60%) 상승해 초당 20점→32점이 됩니다. 나머지 1곳은 그대로 20점입니다. 열세 측이라도 벌어진 차이를 단번에 뒤집기는 어렵다는 뜻이므로, 초반 사이클(1~23분)에서 격차를 만들지 않는 것이 후반 추격보다 훨씬 중요합니다.

어느 건물에서 발동할지 결정 기준은 비공개 미확인

3종 중 "1곳에서만" 발동한다고만 되어 있을 뿐, 어떤 건물이 선택되는지(점령 순서·산출량 기준 등)는 명시되지 않았습니다.

맹호성·비룡성 모두 1차 산출은 15~23분 사이에 확정됩니다. 여기서 벌어진 격차는 추격 메커니즘(3종 중 1곳에만, 격차 비율만큼)으로는 완전히 메워지지 않습니다. 2차 쟁탈에 힘을 아끼기보다 1차 쟁탈에서 이기는 쪽이 훨씬 이득입니다. 이번 시즌에는 장작영 버프를 기다릴 필요도 없으니, 1차부터 책략을 걸고 바로 총력전입니다.

초반에 끊기지 않고 버티는 쪽이 이깁니다 확인

과반 누적 순간 즉시 확정되는 구조라, 쟁탈창 초반부터 진입해 지속적으로 주둔하는 쪽이 유리합니다. 뺏기더라도 누적 시간은 유지되니(재점령 시 이어서 누적) 계속 재탈환하면 됩니다. 병력을 잃으면 상대의 개인 포인트(중상 1명당 1점)를 채워주므로, 교전 자체를 짧게 끝내는 것이 최선입니다.

30부대 상한은 상대에게도 같습니다 확인

상대도 한 건물에 30부대까지만 넣을 수 있으므로, 우리 조의 부대 질(티어)이 그대로 승부가 됩니다. 가장 강한 30부대를 가산 버프 맹호성에, 다음 30부대를 나머지 맹호성에 배치하는 순서가 중요합니다. 건물 밖에 남는 병력은 교체 투입과 공성 지원에 씁니다.

열세일 때는 상대의 과반 도달을 늦추는 것만으로 가치가 있습니다 확인

과반에 도달하기 전까지는 아무리 오래 점유해도 확정되지 않습니다. 점령이 어렵다면 상대가 과반(맹호성 6분·비룡성 7.5분)에 도달하지 못하도록 끊임없이 흔드는 것만으로 그 사이클의 산출을 무산시킬 수 있습니다. 상대가 횡소천군·견불가최를 켠 직후 5분은 피하고, 종료 후에 치는 것이 효율적입니다 — 적군 책략 현황이 전장에 표시됩니다.

개인 구간 보상은 주둔 시간을 따라옵니다 확인

맹호성·비룡성에 6~7.5분씩 주둔하면 점령 개인 포인트(500~800/s)가 자연스럽게 쌓입니다. 개인 랭킹이 없어져 남과 경쟁할 필요가 없으므로, 별도 개인 임무 없이 동맹 작전대로 움직이는 것이 곧 개인 보상 극대화입니다.

분대 전장은 별도 작전이 필요합니다 미확인

분대는 이제 자기 전장에서 자기 상대와 싸웁니다. 분대 결과가 동맹 승패에 반영되는지에 따라 분대 작전의 무게가 달라집니다. 반영되지 않는다면 분대는 개인 포인트 구간 보상을 목표로 위와 같은 동선(맹호성 → 비룡성 → 도적거점)을 그대로 따르면 됩니다.

  2. 도적거점 라운드별 포인트(점증 폭), 조운부두·장작영 1회 포인트 값 변경 여부
  3. 책략 최대 사용 횟수·재사용 대기 — 대장별인지 동맹 공용인지
  4. 주력군·분대 정원, 신청 종료 시각, 분대 결과의 동맹 승패 반영 여부
  5. "지도 중앙 비룡성"이 어느 건물인지, 3급 하향 후 새 명칭·아이콘·산출량
